# EPUB Reader

A lightweight EPUB reader for React Native applications.

## Privacy Policy

**Last updated: August 30, 2026**

EPUB Reader is designed to display EPUB books within React Native applications. This library itself does not collect, store, or transmit personal information.

### Data Processing

* EPUB files selected by the user are processed locally on the device.
* The library does not upload EPUB files or their contents to any external server.
* The library does not collect names, email addresses, passwords, contacts, location data, or other personal information.
* The library does not provide analytics or tracking functionality by itself.
* No user account is required to use the library.

### Third-Party Services

The library may be used within applications that integrate third-party services such as advertising, analytics, or crash reporting. Those services are controlled by the application that integrates this library and may have their own privacy policies.

The library itself does not send EPUB content or reading activity to third-party services.

### Children's Privacy

This library does not knowingly collect personal information from children or any other users.

### Changes to This Privacy Policy

This Privacy Policy may be updated when the library's functionality changes. Any changes will be reflected in this document with an updated revision date.

### Contact

If you have questions about this Privacy Policy or the library, please open an issue in this repository.
